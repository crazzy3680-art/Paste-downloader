Tentang Paste Downloader

Paste Downloader adalah aplikasi web pengunduh media (*media downloader*) modern yang dirancang untuk memudahkan pengguna dalam menyimpan konten berupa video (MP4) dan musik/suara (MP3) dari platform sosial media populer seperti TikTok dan Instagram.

Aplikasi ini dibangun menggunakan arsitektur HTML, CSS (Tailwind), dan JavaScript murni yang sangat ringan (*lightweight*), disesuaikan khusus agar dapat dijalankan dan dikembangkan langsung melalui TrebEdit (Mobile HTML Editor) tanpa memerlukan setup server node.js yang rumit.

Fitur Utama Aplikasi

Pengunduh TikTok MP4 & MP3

Unduh video TikTok HD tanpa watermark serta konversi langsung audio lagu TikTok ke format MP3.

Pengunduh Instagram Reels & Posts

Simpan video Reels, video postingan, dan Audio musik Instagram dengan mudah hanya dengan satu klik.

Fitur Quick Paste

Tombol tempel otomatis dari papan klip (*clipboard*) HP untuk efisiensi waktu pengguna.

Berbasis TrebEdit Compatible

Kode terkonsolidasi dalam 1 file tunggal yang memudahkannya untuk diedit, dipelajari, dan dijalankan di TrebEdit Mobile.

Cara Menggunakan Aplikasi

1

Salin Tautan

Buka aplikasi TikTok atau Instagram, pilih konten lalu klik "Bagikan" -> "Salin Tautan".

2

Tempel di Web

Masudkan tautan ke kolom input dengan menekan tombol "Tempel".

3

Pilih Format

Pilih format output yang diinginkan (MP4 untuk video atau MP3 untuk musik).

4

Klik Unduh

Tekan tombol hitam "Unduh" berteks putih, lalu simpan file hasil pengunduhan ke galeri HP.

Masalah Kendala & Cara Mengatasinya

Kendala 1: Link Tidak Valid / Gagal Memproses

Penyebab: Format tautan salah atau akun target berstatus Privat (Private Account).

Solusi: Pastikan tautan berasal dari postingan publik. Hindari menyalin link dari pesan privat atau Story yang sudah kadaluarsa.

Kendala 2: Tombol "Tempel" Tidak Berfungsi

Penyebab: Browser HP menolak izin akses Clipboard (*Clipboard Permission*).

Solusi: Tekan lama pada kolom input teks lalu pilih opsi "Paste / Tempel" secara manual dari sistem HP Anda.

Kendala 3: Hasil Download Terbuka di Browser Bukan Tersimpan

Penyebab: Pengaturan default browser mobile yang langsung memutar media.

Solusi: Tekan lama pada tombol "Simpan File" di hasil download, lalu pilih menu "Download Link" / "Simpan Tautan".

Kebijakan Privasi

Komitmen kami terhadap keamanan data dan perlindungan privasi pengguna.

1. Pengumpulan Data

Paste Downloader TIDAK MENGUMPULKAN atau menyimpan data pribadi pengguna. Kami tidak memerlukan pendaftaran akun, nama, alamat email, atau nomor telepon untuk menggunakan layanan ini.

2. Pengolahan Tautan (URL)

Tautan TikTok dan Instagram yang Anda masukkan hanya diproses secara sementara untuk keperluan ekstraksi file media MP3/MP4. Tautan tersebut tidak disimpan dalam basis data permanen kami.

3. Hak Cipta & Penggunaan Konten

Paste Downloader tidak memiliki hak cipta atas video atau audio yang diunduh. Seluruh hak cipta dimiliki sepenuhnya oleh kreator konten asli. Pengguna bertanggung jawab penuh atas penggunaan file yang diunduh dan disarankan untuk menggunakannya hanya untuk keperluan pribadi non-komersial.

4. Keamanan Lokal (TrebEdit Environment)

Aplikasi web ini berjalan di sisi klien (*client-side*), sehingga aman dijalankan di dalam lingkungan editor TrebEdit tanpa risiko kebocoran data pribadi Anda.
